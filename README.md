# AR 방탈출

학생이 교실에 붙은 이미지를 태블릿 카메라로 비추면 증강현실 카드가 떠오르고,
문제를 풀어 열쇠 조각을 모아 최종 암호로 탈출하는 수업용 도구입니다.

앱 설치가 필요 없고, 빌드 도구도 쓰지 않습니다. 정적 파일 그대로 동작합니다.

**바로 써 보기 → https://cleveranawim-source.github.io/ar-escape/**

HTTPS 로 서비스되므로 학생 태블릿에서 카메라가 바로 열립니다.
학생에게는 이 주소만 알려 주면 됩니다.

## 실행 (내 컴퓨터에서)

```bash
./serve.sh          # http://localhost:8000
./serve.sh 3000     # 포트 지정
```

- 카메라는 **HTTPS 또는 localhost** 에서만 열립니다. 파일을 더블클릭해 여는 방식(`file://`)은 동작하지 않습니다.
- 같은 와이파이의 태블릿에서 카메라까지 쓰려면 HTTPS 주소가 필요합니다.
  위의 GitHub Pages 주소를 쓰거나, `cloudflared tunnel --url http://localhost:8000` 같은 터널을 쓰세요.
- `main` 에 push 하면 GitHub Pages 가 1~2분 안에 자동으로 갱신됩니다.

## 화면

| 주소 | 용도 |
|---|---|
| `index.html` | 시작 화면 · 샘플 방탈출 즉석 생성 |
| `admin.html` | 교사 제작 스튜디오 (이미지 등록 → 문제 입력 → AR 컴파일 → 배포) |
| `play.html` | 학생 플레이 (AR 모드 / 카메라 없는 연습 모드) |
| `markers.html` | 인쇄용 마커 생성 (A4 한 장에 2개로 인쇄됨) |
| `lab.html` | 실물 인식 테스트 — 학교에 있는 물건이 단서로 쓸 만한지 현장에서 측정 |
| `board.html` | 실시간 현황판 — 모둠별 진행 상황을 교사 화면에서 |

## 기본 샘플 — 「마음의 방」

시작 화면의 `샘플 방탈출 만들기` 를 누르면 사회정서학습(SEL) 방탈출이 3초 만에 만들어집니다.
CASEL 5역량을 자물쇠 하나씩에 배치했습니다.

| 단서 | 역량 | 다루는 상황 |
|---|---|---|
| 1 거울 | 자기 인식 | 감정에 이름 붙이기 |
| 2 모래시계 | 자기 관리 | 단톡방에서 치미는 충동 다루기 |
| 3 나침반 | 사회적 인식 | 친구의 행동을 넘겨짚지 않기 |
| 4 퍼즐 조각 | 관계 기술 | 나-전달법으로 부탁하기 |
| 5 수정 구슬 | 책임 있는 의사결정 | 부탁을 거절하는 기준 세우기 |

문제·힌트·해설은 모두 제작 스튜디오에서 고칠 수 있습니다.
교과나 학년에 맞게 바꿔 쓰는 것을 전제로 만든 출발점입니다.

## 실물을 단서로 쓰기

인쇄한 마커 대신 **학교에 원래 있는 것**을 단서로 쓸 수 있습니다.
게시판 포스터, 학급 시간표, 액자, 안내 표지판, 학생 작품, 복도 안내도처럼
평평하고 · 고정되어 있고 · 무늬가 빽빽한 대상이 잘 됩니다.

다만 MindAR 은 **평면 이미지 매칭** 엔진입니다.
화분·소화기 같은 입체물은 각도가 바뀌면 특징점이 어긋나 실패하고,
유리·코팅면은 반사로 놓치기 쉽습니다. 되는지 안 되는지는 그 앞에서 재 보는 수밖에 없습니다.

`lab.html` 이 그 측정을 대신해 줍니다.

1. 후보를 사진으로 찍어 올립니다 (적합도 예상 점수가 나옵니다)
2. 컴파일합니다
3. **그 물건 앞으로 가서** 카메라를 켜고, 안내에 따라 자세를 바꿉니다
   — 정면 50cm → 정면 2m → 왼쪽 45° → 오른쪽 45° → 움직이며
4. 자세별 인식 유지율과 종합 판정(안정 / 보통 / 부적합)이 나옵니다

판정이 **안정**으로 나온 사진을 그대로 제작 스튜디오에 올려 방탈출을 만들면 됩니다.
"정면에서만 인식됩니다" 같은 진단이 함께 나오므로, 학생 동선을 어떻게 잡을지도 결정할 수 있습니다.

## 수업 준비 순서

1. **마커 준비** — `markers.html` 에서 뽑거나, 교과서 삽화·사진을 씁니다.
   무광 용지에 인쇄해 벽에 평평하게 붙이세요. 코팅지는 조명이 반사되어 인식이 어렵습니다.
2. **문제 붙이기** — `admin.html` 에서 인식할 사진을 올리고 문제·힌트·열쇠 조각을 입력합니다.
   **튀어나올 이미지**(사진·그림·힌트 조각)를 함께 넣으면 인식되는 순간 사진 위로 솟아오릅니다.
   비워 두면 문제 카드가 대신 솟아오릅니다. 학생은 그걸 본 뒤 「문제 보기」를 눌러야 문제가 열립니다.
   업로드하면 인식 적합도 점수가 자동으로 표시됩니다. 34점 미만이면 다른 이미지를 권합니다.
3. **AR 컴파일** — 버튼 하나로 카메라가 알아볼 형태로 변환합니다. 이미지 1장당 5~15초.
   이미지를 추가·교체·삭제하거나 **순서를 바꾸면 다시 컴파일**해야 합니다.
4. **배포** — 아래 참고.

## 실시간 현황판

수업 중에 모둠이 어디까지 갔는지, 어느 문제에서 막혔는지를 교사 화면에서 실시간으로 봅니다.

한 번만 설정하면 됩니다 — Firebase Realtime Database 를 만들고(무료),
그 주소를 `js/live.js` 의 `DB_URL` 에 넣습니다. 자세한 절차는 `board.html` 을 열면 화면에 나옵니다.
비워 두면 전송 코드가 아예 돌지 않고 게임은 지금과 똑같이 동작합니다.

쓰는 법:

1. `board.html` 에서 **방 코드**(반 이름, 예: `3-1`)를 입력합니다
2. 화면에 만들어진 학생용 주소를 공유합니다 — `play.html?src=…&room=3-1`
3. 학생이 모둠 이름을 넣고 시작하면 현황판에 나타납니다
4. 다음 반 전에 **「이 방 기록 지우기」**

### 복귀 시각 (야외 활동)

교실 밖에서 하는 활동이라면 **「10시 40분까지 교실로」** 를 현황판에서 정할 수 있습니다.
경과 시간이 아니라 **절대 시각**을 공유하므로, 태블릿이 튕겨서 다시 들어와도·늦게 시작해도
모두 같은 시각에 돌아옵니다.

- 학생 화면 아래에 `🏫 10:40까지 교실로 · 12:34 남음` 이 계속 떠 있습니다
- **5분 전·2분 전·정각**에 진동과 소리로 알립니다. 밖에서는 화면만 봐서는 놓치니까요
- 정각이 되면 `🏫 교실로 돌아가세요` 로 붉게 바뀝니다 (게임은 계속됩니다)
- **「+5분 연장」** 을 누르면 밖에 있는 모든 기기에 25초 안에 반영됩니다

기기 시계가 틀어져 있어도 어긋나지 않도록 서버 시각과의 차이를 재서 보정합니다.

현황판에 보이는 것: 모둠별 진행률·경과 시간·지금 붙어 있는 단서와 시도 횟수·힌트 사용·🎁 보너스 성공 여부.
한 문제에서 3번 넘게 틀리거나 3분 넘게 머물면 **막힘**으로 빨갛게 표시되니, 그 모둠에게 가시면 됩니다.

### 복귀 시각과 공지 (야외 활동용)

현황판에서 **복귀 시각**(「10시 40분까지」)을 정하면 모든 기기가 그 시각까지 카운트다운하고,
5분 전·2분 전·정각에 진동과 소리로 알립니다. 절대 시각이라 튕겨서 다시 들어와도 같은 값이 유지되고,
「+5분 연장」은 밖에 있는 기기까지 곧바로 닿습니다.

**공지**를 보내면 모든 기기에 전체 화면으로 뜹니다(최대 25초). 누가 확인했는지도 현황판에 나옵니다.


Firebase SDK 는 쓰지 않습니다. 쓰기는 REST(PATCH), 읽기는 `EventSource`(SSE) 라
학생 기기가 추가로 내려받는 파일이 없습니다.

> 보안 규칙은 방 코드를 아는 사람이면 읽고 쓸 수 있게 열어 둡니다. 수업용 임시 기록이라 괜찮지만
> **모둠 이름에 학생 실명을 넣지 마세요.** 「3모둠」처럼 쓰시면 됩니다.

## 배포

만든 자료는 **그 브라우저에만** 저장됩니다(IndexedDB). 다른 기기로 옮기려면 내보내기를 씁니다.

1. 제작 스튜디오에서 `📤 시나리오 파일 내보내기` → `.json` 다운로드
2. 그 파일을 `scenarios/` 폴더에 넣기
3. 학생에게 주소 공유 — `play.html?src=scenarios/파일이름.json`

`scenarios/README.md` 에 주의사항이 있습니다. **정답이 파일에 그대로 들어 있으므로**
경쟁이 중요한 상황이라면 감독 하에 진행하세요.

## 오프라인 동작

A-Frame 과 MindAR 을 `vendor/` 에 함께 넣어 두었습니다(약 3MB).
CDN 이 막혀 있어도 동작하고, 막히지 않았더라도 학생 기기가 매번 3MB 를 내려받지 않습니다.
`vendor/` 가 없으면 자동으로 CDN 으로 넘어갑니다.

`sw.js`(서비스워커)가 한 번 받은 파일을 기기에 남깁니다. 앱 파일은 네트워크 우선이라
수정하면 새로고침으로 곧바로 반영됩니다. 캐시를 강제로 비우려면 `sw.js` 의 `VERSION` 을 올리세요.

## 개발

```bash
node tools/check.mjs    # 모든 ES 모듈 문법 검사
```

| 파일 | 역할 |
|---|---|
| `js/model.js` | 시나리오 데이터 모델 · 채점 · 무결성 검사 |
| `js/store.js` | IndexedDB(시나리오) + localStorage(진행상황·기록) |
| `js/ar.js` | MindAR/A-Frame 래퍼 · 타겟 컴파일러 · 라이브러리 로더 |
| `js/arcard.js` | AR 카드 렌더러 (A-Frame 텍스트가 한글을 못 써서 캔버스로 그림) |
| `js/markers-draw.js` | 시드 기반 고특징점 마커 생성 |
| `js/util.js` | DOM · 토스트 · 파일 I/O · 마커 적합도 채점 |
