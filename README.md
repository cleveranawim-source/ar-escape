# AR 방탈출

학생이 교실에 붙은 이미지를 태블릿 카메라로 비추면 증강현실 카드가 떠오르고,
문제를 풀어 열쇠 조각을 모아 최종 암호로 탈출하는 수업용 도구입니다.

앱 설치가 필요 없고, 빌드 도구도 쓰지 않습니다. 정적 파일 그대로 동작합니다.

## 실행

```bash
./serve.sh          # http://localhost:8000
./serve.sh 3000     # 포트 지정
```

- 카메라는 **HTTPS 또는 localhost** 에서만 열립니다. 파일을 더블클릭해 여는 방식(`file://`)은 동작하지 않습니다.
- 같은 와이파이의 태블릿에서 카메라까지 쓰려면 HTTPS 주소가 필요합니다.
  GitHub Pages 로 올리거나, `cloudflared tunnel --url http://localhost:8000` 같은 터널을 쓰세요.

## 화면

| 주소 | 용도 |
|---|---|
| `index.html` | 시작 화면 · 샘플 방탈출 즉석 생성 |
| `admin.html` | 교사 제작 스튜디오 (이미지 등록 → 문제 입력 → AR 컴파일 → 배포) |
| `play.html` | 학생 플레이 (AR 모드 / 카메라 없는 연습 모드) |
| `markers.html` | 인쇄용 마커 생성 (A4 한 장에 2개로 인쇄됨) |

## 수업 준비 순서

1. **마커 준비** — `markers.html` 에서 뽑거나, 교과서 삽화·사진을 씁니다.
   무광 용지에 인쇄해 벽에 평평하게 붙이세요. 코팅지는 조명이 반사되어 인식이 어렵습니다.
2. **문제 붙이기** — `admin.html` 에서 이미지를 올리고 문제·힌트·열쇠 조각을 입력합니다.
   업로드하면 인식 적합도 점수가 자동으로 표시됩니다. 34점 미만이면 다른 이미지를 권합니다.
3. **AR 컴파일** — 버튼 하나로 카메라가 알아볼 형태로 변환합니다. 이미지 1장당 5~15초.
   이미지를 추가·교체·삭제하거나 **순서를 바꾸면 다시 컴파일**해야 합니다.
4. **배포** — 아래 참고.

## 배포

만든 자료는 **그 브라우저에만** 저장됩니다(IndexedDB). 다른 기기로 옮기려면 내보내기를 씁니다.

1. 제작 스튜디오에서 `📤 시나리오 파일 내보내기` → `.json` 다운로드
2. 그 파일을 `scenarios/` 폴더에 넣기
3. 학생에게 주소 공유 — `play.html?src=scenarios/파일이름.json`

`scenarios/README.md` 에 주의사항이 있습니다. **정답이 파일에 그대로 들어 있으므로**
경쟁이 중요한 상황이라면 감독 하에 진행하세요.

## 오프라인 동작

A-Frame 과 MindAR 을 `vendor/` 에 함께 넣어 두었습니다(약 3MB).
CDN 이 막혀 있어도 동작하고, 막히지 않았더라도 학생 기기가 매번 3MB 를 내려받지 않습니다.
`vendor/` 가 없으면 자동으로 CDN 으로 넘어갑니다.

`sw.js`(서비스워커)가 한 번 받은 파일을 기기에 남깁니다. 앱 파일은 네트워크 우선이라
수정하면 새로고침으로 곧바로 반영됩니다. 캐시를 강제로 비우려면 `sw.js` 의 `VERSION` 을 올리세요.

## 개발

```bash
node tools/check.mjs    # 모든 ES 모듈 문법 검사
```

| 파일 | 역할 |
|---|---|
| `js/model.js` | 시나리오 데이터 모델 · 채점 · 무결성 검사 |
| `js/store.js` | IndexedDB(시나리오) + localStorage(진행상황·기록) |
| `js/ar.js` | MindAR/A-Frame 래퍼 · 타겟 컴파일러 · 라이브러리 로더 |
| `js/arcard.js` | AR 카드 렌더러 (A-Frame 텍스트가 한글을 못 써서 캔버스로 그림) |
| `js/markers-draw.js` | 시드 기반 고특징점 마커 생성 |
| `js/util.js` | DOM · 토스트 · 파일 I/O · 마커 적합도 채점 |
