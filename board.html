⚙️ 먼저 한 번만 설정하세요

모둠 진행 상황을 실시간으로 주고받으려면 Firebase Realtime Database 주소가 필요합니다. 무료이고, 한 번만 만들면 계속 씁니다.

설정 방법 (5분)
  1. Firebase 콘솔에서 프로젝트 만들기 — 이름은 아무거나(예: ar-escape). Google 애널리틱스는 꺼도 됩니다.
  2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기. 위치는 싱가포르(asia-southeast1)가 한국에서 가장 빠릅니다.
  3. 보안 규칙은 테스트 모드로 시작한 뒤, 규칙 탭에서 아래로 바꿔 주세요.
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        ".write": true,
        ".validate": "$room.length <= 24"
      }
    }
  }
}
  1. 데이터 탭 맨 위의 주소(https://….firebasedatabase.app)를 복사합니다.
  2. 그 주소를 js/live.js 의 DB_URL 에 넣고 커밋·푸시하면 끝입니다.

이 규칙은 방 코드를 아는 사람이면 누구나 읽고 쓸 수 있게 둔 것입니다. 수업용 임시 기록이라 괜찮지만, 모둠 이름에 학생 실명을 넣지 마세요. 「3모둠」처럼 쓰시면 됩니다.
